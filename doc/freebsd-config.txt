
Example configuration for FreeBSD:

Add the following lines to the file /etc/ntp.conf:

# usbdcf77re (SHM driver)
server 127.127.28.2


Then restart ntpd, check if the SHM is there:
command: "ipcs -m"

Output:

Shared Memory:
T           ID          KEY MODE        OWNER    GROUP
m        65536   1314148402 --rw-rw-rw- ntpd     ntpd


Start usbdcf77re with the correspondig SHM:

command: "usbdcf77re -d 65536"

After the device is in sync check the status of ntpd:


command: "ntpq -pn"

Output:
